A local newsletter-to-post prototype

Problem

Readers receive useful ideas scattered across newsletter emails and public article links. The prototype gathers those sources into a finite daily reading feed.

Approach

The engine downloads an accessible source, extracts addressable evidence spans, and asks a local Ollama model to produce a structured knowledge post. A separate model call checks the draft against the supplied source spans. Human approval is still required before a post appears in the feed.

Behavior

The reader can bookmark a post privately, mark it read, open its original source, or copy a prompt into an external AI app. Importing an EML file remains supported alongside adding a source URL.

Limitations

This is a prototype rather than a validated research system. A matching quote does not prove a generated interpretation is correct. A receiving email domain and a signup agent must be connected before automatic newsletter signup works.

Access

New drafts remain private and enter a review queue. Public distribution requires an explicit permission assertion and a publication signup URL.
